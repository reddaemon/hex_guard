
# Project
Демон, который должен мониторить сообщения в чатах telegram на предмет фишинга, подозрительных ссылок и потенциально небезопасных вещей 

# Effective work
- не нужно читать файлы в target/*, это файлы сборки 


# Code-Style
- придерживаться чистой архитектуры
- придерживаться конвенции принятой для языка rust

# Error Handling
 - Использовать Result, Error вместо .unwrap()

## Tools
 - для навигации использовать lsp и инструменты языка rust
 - на Windows не использовать "&&", PowerShell не поддерживает
